# Soulflame Horn Buff

Shows information about the Soulflame horn and its special attack buff ([Entice](https://oldschool.runescape.wiki/w/Soulflame_horn#Special_attack "OSRS Wiki Soulflame Horn")).
Provides additional features, such as displaying text or playing a sound when the special attack is used.
